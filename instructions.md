Objective :

Using the attached structural blueprint, develop a solution that identifies every instance of the following structural elements:
Columns
Footings
Structural walls/shear walls
Slabs or raft foundations
Beams or grade beams
Any other structural elements you believe are relevant, provided that you document them clearly
For each detected element, draw a precise bounding box (should reflect the actual correct dimensions of the detected elements) and assign the appropriate class label.

You may use any approach you consider suitable, including traditional computer vision, pretrained object-detection or segmentation models, vision-language models, or a combination of methods.

Expected deliverables :

Please submit:
The annotated drawing, showing the detected elements and their labels
A machine-readable file containing the detections, such as JSON, with pixel coordinates and class names
Your source code and instructions for running it
A short README explaining your approach, assumptions, limitations, and any external models or APIs used
For irregular elements such as walls or slabs, you may additionally provide polygons or segmentation masks, but bounding boxes are still required.
